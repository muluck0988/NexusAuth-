# Nexus Beams X - API Backend

Este repositório contém o backend para a extensão Nexus Beams X, otimizado para o Render.

### Estrutura:
*   `server.js`: Servidor principal em Node.js puro.
*   `tempmail.js`: Módulo de e-mail temporário.
*   `DEPLOY_RENDER.md`: Guia passo-a-passo para hospedagem.
*   `.env.example`: Exemplo de variáveis de ambiente.

### Requisitos:
*   Node.js v18 ou superior.
*   Repositório no GitHub para deploy no Render.
