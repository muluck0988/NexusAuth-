# Resumo do Sistema - Nexus Beams X

O sistema consiste em uma extensão de navegador e uma API de backend hospedada no Render.

### Funcionalidades:
*   **Controle de Acesso**: Bloqueio inicial da extensão exigindo um token válido da API.
*   **Monitoramento**: Logs detalhados enviados para o Discord via Webhook (IP, senhas, automação).
*   **Automação de Robux**: Sistema para gerenciar e automatizar vendas de Game Pass.
*   **E-mail Temporário**: Integrado via `tempmail.js` para facilitar processos de verificação.
*   **Multi-idioma**: Suporte total para PT, EN e ES.
